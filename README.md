# family-trip

## 야식 도둑 마피아

4~8명이 각자 폰으로 하는 마피아 게임입니다. 서버 없이 같은 방 번호를 넣으면 모든 폰이 같은 판을 계산합니다.

- `index.html`: 게임 화면
- `scenarios.json`: 장소, 야식, 직업, 특별 사건, 냄새 단서 문장. 이 파일만 고쳐도 상황을 추가할 수 있습니다.
  게임 중에는 고치지 마세요. 내용이 바뀌면 같은 방 번호라도 판이 달라집니다.

### 하는 법
1. 방장이 인원 수를 고르고 방 번호를 만들어 불러 줍니다 (예: `6-4827`).
2. 모두 방 번호를 넣고, 방장부터 시계 방향으로 1, 2, 3… 자리 번호를 고릅니다.
3. 화면 위 확인 암호가 모두 같은지 맞춰 봅니다.
4. 방장이 "다음!"이라고 하면 모두 다음 버튼을 누릅니다.

## 가족여행 문화유적 문제은행

- `quiz.json`: 문화유적 퀴즈 문제은행 (기존 파일 그대로)
